# Internship Recruiting Analytics Dashboard

A personal analytics project tracking my 2026 internship recruiting process using SQL and Tableau Public.

## Live Dashboard
[View on Tableau Public](https://public.tableau.com/app/profile/mohammed.ali3427/viz/InternshipRecruitingDashboard2026/Dashboard1#1)

## Project Summary
- Logged 23 applications across 10+ industries
- Built a SQLite database and wrote SQL queries to analyze conversion rates
- Identified a 48% screen rate from LinkedIn cold outreach
- Visualized pipeline funnel, response time by company, and industry breakdown in Tableau Public

## Key Insights
- Rejected: 10 | Screened: 7 | Interviewing: 4
- Fastest responder: IBM (5 days) | Slowest: McKinsey (24 days)
- 100% of applications via LinkedIn — no referral pipeline used
- Data suggests adding networking/referrals could significantly improve conversion

## Tools Used
- SQL (SQLite) — data storage and querying
- Tableau Public — data visualization and dashboard
- Excel/CSV — data collection and export

## Files
- `queries.sql` — all SQL queries used for analysis
- `recruiting_tracker.csv` — anonymized application data
